# Bill Tracking Templates

> **Last updated**: April 4, 2026
> **Purpose**: Track bills relevant to CoTrackPro and Access To campaigns through the legislative process.

## HOW TO USE THIS FILE

1. When a relevant bill is introduced, add it to the appropriate campaign section below
2. Update the status as it moves through committees and floor votes
3. Use the tracking links to monitor hearing schedules and amendments
4. Cross-reference with `senate-committees.md` to know which committee members to target

---

## BILL STATUS KEY

| Status | Meaning |
|--------|---------|
| **Introduced** | Filed by sponsor, awaiting committee assignment |
| **In Committee** | Assigned to committee, awaiting hearing |
| **Hearing Scheduled** | Committee hearing date set |
| **Heard** | Testimony taken, awaiting committee vote |
| **Passed Committee** | Voted out of committee, heading to floor |
| **On Calendar** | Scheduled for floor debate |
| **Passed Chamber** | Passed originating chamber, sent to other chamber |
| **In Conference** | Differences being reconciled between chambers |
| **Truly Agreed** | Both chambers agreed on final version |
| **Sent to Governor** | Awaiting signature or veto |
| **Signed** | Enacted into law |
| **Vetoed** | Governor vetoed; may be overridden |
| **Dead** | Did not advance before deadline |

## BILL TRACKING TEMPLATE

Copy this block for each bill you're tracking:

```
### [BILL NUMBER] — [SHORT TITLE]

- **Sponsor**: [Name] ([Chamber], District [#])
- **Filed**: [Date]
- **Committee**: [Committee Name]
- **Status**: [See key above]
- **Last action**: [Date] — [Description]
- **Next action**: [Date] — [Hearing/Vote/etc.]
- **CoTrackPro relevance**: [Why this matters]
- **Campaign**: [CoTrackPro / Access To Justice / etc.]
- **Our position**: [Support / Oppose / Monitor / Neutral]
- **Key contacts**: [Who to call/email about this bill]
- **Tracking links**:
  - Senate: https://www.senate.mo.gov/26info/bts_web/Bill.aspx?SessionType=R&BillID=[ID]
  - House: https://house.mo.gov/Bill.aspx?bill=[NUMBER]&year=2026&code=R
  - LegiScan: https://legiscan.com/MO/bill/[NUMBER]/2026

**Notes**:
[Any relevant context, amendments, opposition, etc.]
```
