## QUICK DECISION TREE

```
Which letter variant should I use for Senator [X]?

1. Is this senator on the Judiciary committee?
   YES → Use Access To Justice letter
   
2. Is this senator on Families, Seniors and Health?
   YES → Use Access To Health letter (or Safety if DV-focused)
   
3. Is this senator on Education?
   YES → Use Access To Education letter
   
4. Is this senator on Economic/Workforce Development?
   YES → Use Access To Jobs letter
   
5. Is this senator in the STL metro area?
   YES → Use CoTrackPro intro letter with local constituent angle
   
6. Is this senator in leadership (Floor Leader, Caucus Chair, etc.)?
   YES → Use CoTrackPro intro letter with leadership angle
   
7. None of the above?
   → Use standard CoTrackPro intro letter
```
